# M0 Studio 實測清單(需在有 Roblox Studio + Rojo 的機器上做)

前置:`rokit install` → `rojo serve` → Studio 安裝 Rojo plugin 連線 → Play。

## A. 球面格位(PlanetDemo)
- [ ] 球體出現在 (0,300,0),半徑約 111 studs,表面有 864 個彩色方塊
- [ ] 6 種顏色分屬 6 個面,面與面交界無明顯縫隙/重疊
- [ ] 各方塊大小肉眼一致(靠近立方體角落的略小是正常,差距應 < 1.6×)

## B. 球面重力(SphereGravity)— **最大風險**
- [ ] 出生在北極,WASD 可繞星球走完一整圈、不掉出表面
- [ ] 走過赤道、南極時身體仍朝外站直
- [ ] 空白鍵可跳、落回表面,無抖動
- [ ] 相機跟隨不暈(轉過極點時沒有突然翻轉)
- [ ] 手機觸控:目前只做鍵盤,觸控搖桿另列待辦
- 結論:通過 → 方案 A 定案;抖動/暈無法解 → 改方案 B(圓盤島)

## C. SolidCraft 模型匯入
- [ ] 用 SolidCraft MCP 建一個砲台 → 匯出 glTF/OBJ → Studio Asset Importer
- [ ] 記錄:單位縮放(目標 1 格 = 12 studs)、面數是否被拒、材質是否保留

### C 已驗證的部分(2026-10-29,SolidCraft MCP 端)
- 建模成功:底座 10×10×2 + 炮管 Ø6×6 → `assets/PulseTurret_test.obj`
- **匯出格式只有 stl / obj / step / 3mf / urdf**(不支援 glTF/glb)→ 本專案統一匯出 **OBJ**,Studio Asset Importer 可讀
- OBJ 檔頭註明單位 mm、**Z 軸向上**(Roblox 是 Y 向上)→ 匯入後要確認方向,必要時在 SolidCraft 建模時把「朝外」軸當 Y 或匯入後旋轉
- 約定:**建模時 1 mm = 1 stud**(格位 12×12 → 底座畫 12×12),避免換算
- ⚠ 曲面被切得很細:這個簡單模型就有 **1560 面**(1013 頂點)。建築有多個圓柱時會很快逼近 Roblox 單一 MeshPart 面數上限 → 建模時儘量少用圓柱/大量圓角,或匯入前先簡化;Studio 匯入時實際會不會被拒待實測
- SolidCraft MCP 用法踩點:`batch` 的指令陣列參數叫 `commands`,每個指令用 `{"command":..., "params":{...}}`(不是 `args`);`export` 只能寫進 `...\Temp\solidcraft-mcp-<pid>-*` 再複製

## D. M1 建造 / 採集 / 存檔(需 Studio)
前置:Game Settings → Security → 開啟「Enable Studio Access to API Services」,否則 DataService 會退回記憶體模式(不保存)。
- [ ] 進遊戲後左上顯示「資源:礦石 50」,下方有 7 個建築按鈕
- [ ] 選「礦機」→ 左鍵點任一彩色格位 → 出現黃色方塊、礦石 -20
- [ ] 再選「太陽能板」蓋一格 → 礦石開始每秒 +1(初始 礦石50/金屬10 剛好夠這兩棟)
- [ ] 右鍵點已蓋的建築 → 消失並退回 50% 資源
- [ ] 重複點同一格 → 「這格已經有建築了」
- [ ] 停止再 Play(同帳號)→ 建築與資源還在(代表存檔成功)
- [ ] Output 無紅字;`[PlanetService]` log 顯示蓋/拆
- [ ] 兩人測試(Test → 2 Players):第二位點擊建造 → 「這是別人的星球,只能參觀」
**備註**:Metal 用完後要靠穿梭(岩石星)取得,M2 才會有;目前只能靠拆除退款回收。

## E. M2 時空穿梭(需 Studio)
- [ ] 開局資源(礦石100/金屬15)依序蓋 礦機、太陽能板、時空門(各1)都成功,且剩餘礦石 ≥10
- [ ] 右上「開啟時空門」→ 扣礦石10 → 傳到一顆新星球(岩石/冰/晶體之一),出現發光資源點
- [ ] 走近資源點出現「採集」提示,長按 0.3 秒 → 載重數字增加
- [ ] 載重超過上限時變橘色「⚠超載」;撿到 1.5 倍上限後提示「背包太重了」
- [ ] 按「返航」→ 回母星、資源全數入帳
- [ ] 不按返航等倒數歸零 → 「空間崩塌!」,超載部分只留一半
- [ ] 穿梭中摔死/重生 → 被送回該星球
- [ ] 穿梭中點母星建造 → 「先返航回母星才能建造」
- [ ] 連跳 10 趟,Explorer 看 TripWorld 都有被清掉(無殘留 Part)
**已知缺口**:星球危險區(冰的減速、晶體共振)尚未做。

## F. 中央螢幕 / 好友採集 / 採集節奏(需 Studio,Test → 2 Players)
- [ ] 左下「📡 中央螢幕 (M)」可開關;面板左邊是 6 個面的十字展開圖,蓋建築後對應格會上色(攻擊紅/防禦藍/能源綠/採集黃…)
- [ ] 裂縫降落點(⚠)標在右面;升到 Lv2/Lv3 的建築有白色外框
- [ ] 左下方顯示「母星特產:★…」(5 種,2 種有 ★);其餘 15 種要穿梭才有
- [ ] 裂縫倒數 30 秒 → 訊息區出現「⚠ 第 N 波裂縫 30 秒後開啟」;開戰時面板自動彈出
- [ ] 戰鬥中:怪獸逐隻出現「👾 xx 從裂縫降落」、擊殺出現「💥 擊倒 xx(剩 a/b)」,星核/護盾/牆/怪獸四條會動;戰後 8 秒自動收起
- [ ] 第二位玩家(主人的 Roblox 好友)進入 → 主人的中央螢幕出現「👋 好友 xxx 來到你的星球」,離開出現「🚪 xxx 離開了星球」
- [ ] 好友走到母星上的發光資源點長按 → 主人螢幕出現「⛏ 好友 xxx 在你的星球採集了 ○○ ×40(或剩餘量)」;好友自己的背包增加,主人背包不變
- [ ] 非好友進入 → 顯示「👤 訪客」,採集被拒絕並提示「只有星球主人的好友才能採集」
- [ ] 採集後右上顯示「採集冷卻 N 秒」(Lv1 = 120 秒);擴建星球後秒數變短(滿級 20 秒)
- [ ] 同一資源採滿 20 次 → 提示進入 12 小時冷卻,該資源點在他身上無法再採
- [ ] 資源點被採光變半透明,約 90 秒後重生
**注意**:Studio 測試時「好友」關係取決於測試帳號;單機 2 Players 測試兩人互為好友才會顯示為好友。
