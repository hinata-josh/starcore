## 二、這次做了什麼

- **資源一直是「—」、點了都說「別人的星球」**:Studio 沒開 API 存取時 DataStore 重試要卡 1 分多鐘。→ `DataService` 在 Studio 失敗一次就退記憶體模式;`PlanetService` 載入中改提示「星球載入中」。
- **人不能動、亂飄**:腳插進出生台被物理推、又和 Roblox 原生重力打架。→ 新增 `server/Walkers.server.luau`(角色碰撞群組不碰場景)+ `SphereGravity` 本機 `Gravity = 0`、腳底高度用實際角色算。
- **轉向不順**:相機甩回背後造成繞圈。→ `SphereGravity` 重寫:相機有自己朝向(右鍵拖曳 / Q E / ←→ 轉、滾輪縮放)、平滑加減速與轉身。右鍵「點一下」才拆建築(`BuildUI`)。

## 五、尚未驗證 / 風險
1. **圖片上傳沒打過真的 Roblox**(只有假伺服器)。Decal→Image ID 走 Asset Delivery API,轉不到就用 rbxthumb 顯示圖示(按鈕/卡片維持色塊)。第一次上傳後請看發布視窗訊息。
2. **球面重力 / 新相機操作**只在模擬器跑過,需 Studio 實測(`docs/studio-checklist.md` B 段)。
3. 怪獸移動與翅膀拍動由伺服器每幀更新,實機可能不順;若卡頓,改成 client 端播放動畫。
4. N1 美術是公司素材:體驗改 Public 前,請確認公司是否允許用在 Roblox。
5. 手機觸控:目前只有鍵盤滑鼠操作(轉視角、移動)。
6. **好友穿梭**只測了主人那條路和「陌生人被擋」(模擬器只有一位玩家);好友實際能不能去,要在 Studio Test → 2 Players(兩帳號互為好友)或正式伺服器測。
7. 走路動畫的動畫 ID 是 Roblox 預設的;角色若是自訂動畫包會優先讀角色身上的 Animate。
8. **傳送(大廳→家、拜訪好友、回家)只能在正式伺服器測**:Studio 不支援 TeleportService / ReserveServer。模擬器只驗了主人判定、按鈕、提示與防呆。第一次上線請實測:進遊戲會不會自動到自己的星球、好友能不能互訪、回家鍵。
9. 拜訪的好友若不在他自己的星球(例如他正在別人家),你會到他「沒有主人」的星球,只會看到提示,要按回家。
10. 從好友家回家時,存檔鎖要等前一台伺服器釋放(通常幾秒);若遇到載入變慢屬正常範圍。

## 七、坑(之後改程式要注意)
- `Skin` 的 `reveal` 不能檢查 `Parent`(圖片已載入時會在元件放進畫面前就呼叫)。
- 倒數類 `("%d"):format(x)` 一律先 `math.floor`(Luau 不吃小數)。
- `img_select01` 是實心方塊別當選框;`btn_tab03` 壓扁很醜。
- Roblox 圓柱的軸是 X;直徑取 Y/Z 較小者(壓扁 Z 會變細棍)。
- 測試框架改模擬器「類別方法」要用 `L.nat` 包,且要在第一次建 Runtime 之前改。
- `.ps1` 含中文要 UTF-8 with BOM;改 PowerShell 用 Edit 工具,別用 heredoc 跑 python/sed 改中文或含 `\` 的內容。
